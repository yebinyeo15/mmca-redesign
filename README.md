# MMCA SEOUL | 국립현대미술관 웹사이트 리디자인

국립현대미술관(MMCA) 서울관을 주제로 제작한 웹사이트 리디자인 프로젝트입니다.

현대미술관의 정체성을 살린 미니멀한 디자인과 직관적인 정보 구성을 통해 전시, 교육 프로그램, 관람 정보를 편리하게 확인할 수 있도록 구현했습니다.

## 프로젝트 소개

- **프로젝트명:** MMCA SEOUL Website Redesign
- **프로젝트 유형:** 웹사이트 리디자인 / 퍼블리싱
- **작업 형태:** 개인 프로젝트
- **사용 기술:** HTML5, CSS3, JavaScript, Swiper.js
- **디자인 도구:** Figma
- **배포 플랫폼:** Vercel

## 주요 기능

- **메인 비주얼 슬라이더:** 3장의 전시 이미지가 자동으로 전환되는 HERO 섹션
- **고정형 콘텐츠:** 슬라이드 전환 시 텍스트와 컨트롤 버튼의 위치 유지
- **전시 안내:** 현재전시 및 예정전시 콘텐츠 제공
- **교육·행사:** 어린이·가족 교육, 전시 연계 프로그램, 아티스트 토크 소개
- **미술관 소식:** 공지사항과 관람 관련 정보 구성
- **반응형 레이아웃:** 다양한 화면 크기를 고려한 웹페이지 구현
